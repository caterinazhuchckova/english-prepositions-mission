# English Prepositions — Cosmic Mission FINAL

Финальная пересобранная версия с визуальным трекером прогресса.

## Что реализовано

- 3 переписанные игры: Sentence Builder, Picture Shooter, Type the Preposition.
- Визуальный трекер: 10 SVG-картинок от пустой площадки до полностью построенного космического дома.
- Каждая новая звезда открывает 1 часть дома (максимум 9).
- Последовательное открытие миссий.
- Сохранение прогресса в localStorage.
- Picture Shooter: видимый космический бластер, прицел, наведение, лазерный луч, попадание и промах.
- На компьютере игровой экран рассчитан на размещение внутри одного viewport без вертикального скролла; для мобильных устройств включается обычная прокрутка.
- Исходные учебные картинки сохранены и оптимизированы.
- Аудио можно добавить после распаковки в `assets/sounds/`.

## Аудио

Список ожидаемых файлов находится в `AUDIO_FILES_TO_ADD.txt`.
Без аудио игра не ломается — просто не воспроизводит отсутствующие звуки.

## Публикация

Загрузите содержимое папки в корень нового GitHub-репозитория или на Netlify. `index.html` уже находится в корне.
