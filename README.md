# English Prepositions Space Missions

Самостоятельная геймифицированная A1-игра по английским предлогам места.

Автор: **Katerina Zhuchkova**

## В проекте

- Mission 1 — Sentence Builder
- Mission 2 — Picture Shooter
- Mission 3 — Type the Preposition
- последовательное открытие миссий;
- звёзды и достижения;
- комбо и бонусные очки;
- жизни, таймер и уровни сложности;
- музыка, озвучка и игровые эффекты;
- адаптация под компьютер, планшет и телефон.

## Важно

Все изображения находятся внутри проекта.

Все аудиофайлы подключаются локально из папки:

```text
assets/sounds/
```

Перед загрузкой на GitHub добавьте в эту папку 32 MP3-файла из списка
`AUDIO_FILES_TO_ADD.txt`.

Игра не зависит от старого репозитория или старого сайта.

## Публикация в новом репозитории

1. Создайте новый публичный репозиторий GitHub.
2. Распакуйте архив.
3. Добавьте 32 MP3-файла в `assets/sounds/`.
4. Перетащите в репозиторий всё содержимое папки проекта.
5. Нажмите `Commit changes`.
6. Откройте `Settings → Pages`.
7. Выберите `Deploy from a branch`.
8. Branch: `main`.
9. Folder: `/ (root)`.
10. Нажмите `Save`.
