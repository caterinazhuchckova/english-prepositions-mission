# 2. Общая концепция

Проект представляет собой адаптивный образовательный сайт с тремя интерактивными HTML-играми по теме **Prepositions of Place**.

Игры:

1. **Sentence Builder**
2. **Picture Shooter**
3. **Type the Preposition**

Все три игры:

- предназначены для уровня A1;
- используют одного и того же рыже-белого котёнка;
- используют одинаковый набор учебных картинок;
- используют общую систему звуков;
- запускаются с одной главной страницы;
- работают на компьютере, планшете и телефоне;
- имеют кнопку возврата в главное меню;
- имеют правила игры;
- имеют управление музыкой и игровыми звуками;
- имеют законченный игровой цикл.

# 3. Образовательная цель

Ученик должен научиться понимать и употреблять:

- in
- on
- under
- behind
- next to

Базовая структура предложения:

Смысловые части предложения:

# 15. Sentence Builder

## Механика

1. Показать картинку.
2. Показать 4 перемешанные смысловые плитки.
3. Пользователь нажимает на плитки.
4. Плитки переходят в строку ответа.
5. Повторное нажатие возвращает плитку.
6. Кнопка `CHECK` проверяет порядок.

Пример:

```text
The cat | is | under | the table
```

## Кнопки

- `CHECK`
- `CLEAR`
- `NEXT`

## Звуки

При установке плитки:

- соответствующая озвучка;
- `block_connect.mp3`.

Правильный ответ:

- `correct.mp3`;
- `meow.mp3` или `great_job.mp3` / `excellent.mp3`.

Ошибка:

- `wrong.mp3`;
- `try_again.mp3`.

## Сложность

Easy:

- in, on, under;
- без таймера или Slow;
- 3 жизни;
- без штрафа за первую ошибку.

Medium:

- все 8 предлогов;
- Normal;
- ошибка уменьшает жизнь.

Hard:

- все 8 предлогов;
- Fast;
- штраф по очкам;
- меньше времени.

---

# 16. Picture Shooter

## Механика

1. Показать предлог или предложение.
2. Показать 3–6 картинок.
3. Пользователь нажимает на нужную.
4. Воспроизводится `shot.mp3`.
5. Появляется световой импульс.
6. Ответ проверяется.

Основное задание:

```text
UNDER
```

Допустимый Hard-вариант:

```text
The cat is under the table.
```

## Правильный ответ

- `hit.mp3`;
- `correct.mp3`;
- `meow.mp3` или похвала;
- подсветка карточки;
- начисление очков.

## Ошибка

- `wrong.mp3`;
- `try_again.mp3`;
- уменьшение жизни;
- мягкое покачивание карточки.

## Количество вариантов

- Easy: 3
- Medium: 4
- Hard: 6

Бластер только световой и мультяшный.

---

# 17. Type the Preposition

## Механика

1. Показать картинку.
2. Показать предложение с пропуском.
3. Пользователь вводит предлог.
4. При наборе звучит `typing.mp3`.
5. Нажимает `CHECK`.

Пример:

```text
The cat is ___ the table.
```

## Проверка

- без учёта регистра;
- игнорировать внешние пробелы;
- точка не требуется.

## Кнопки

- `CHECK`
- `CLEAR`
- `NEXT`

## Сложность

Easy:

- первая буква как подсказка;
- in, on, under;
- без строгого таймера.

Medium:

- пустое поле;
- все предлоги;
- Normal.

Hard:

- Fast;
- длинные выражения;
- меньше времени.

---

# 18. Очки

Рекомендуемая система:

- с первой попытки: +10;
- со второй: +7;
- после нескольких ошибок: +5;
- бонус времени: до +5;
- минимальный счёт: 0.

---

# 19. Жизни

По умолчанию:

```text
♥ ♥ ♥
```

В Medium и Hard ошибка уменьшает жизнь.

При 0 жизней открывается итоговый экран.

---

# 20. Таймер

| Скорость | Время |
|---|---:|
| Slow | 30 секунд |
| Normal | 20 секунд |
| Fast | 12 секунд |

Последние 5 секунд визуально выделяются.

`timer.mp3` воспроизводится один раз при входе в последние секунды.

# 21. Раунды

Каждая из 8 картинок используется один раз.

Порядок случайный.
